# Contexto persistente del proyecto

Antes de planificar o modificar NetAssist, lee [docs/MEMORIA_PROYECTO.md](docs/MEMORIA_PROYECTO.md). Contiene el objetivo, el alcance y las fases acordadas con el usuario. Actualiza esa memoria cuando se acuerden cambios de dirección; distingue decisiones, propuestas y trabajo realmente completado.

- Primera versión: fases 1 a 3, centradas en Cisco, VLAN y puertos de acceso. La fase 4 es el siguiente incremento.
- La aplicación web organiza la práctica. El chat acompaña el caso abierto, abajo a la derecha y ampliable.
- Packet Tracer es el laboratorio externo. El intercambio inicial de comandos y salidas es manual, mediante copiar y pegar.
- Una propuesta generada no equivale a una configuración verificada. Diferencia validaciones de código, evidencia aportada y pruebas realizadas en laboratorio.
- Cualquier conexión, inicialización o migración de base de datos debe usar almacenamiento exclusivo de este proyecto. Verifica la ruta o destino efectivo antes de escribir. No interfieras con otras bases ni servicios existentes.
- El mockup es una referencia de interfaz con respuestas de ejemplo; no lo trates como funcionalidad de producción terminada.
