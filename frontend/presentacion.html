¿Qué es una red de computadoras?

Definición simple: dos o más dispositivos conectados que comparten recursos.

En su esencia, una red permite que dispositivos electrónicos se comuniquen intercambiando datos a través de un medio físico o inalámbrico. El objetivo puede ser tan simple como compartir un archivo o tan complejo como habilitar una videollamada global.

Lo fascinante es que, aunque no los veamos, seguimos dependiendo de ellas cada minuto: el correo electrónico, las transmisiones en vivo, las transferencias bancarias, todo pasa por redes.

Topologías: cómo se organizan los dispositivos

La disposición física o lógica de una red.

La topología define no solo la conexión, sino también qué tan resistente es la red a fallos:

  • Bus: Todos los dispositivos comparten un medio común. Fácil de instalar, pero un fallo puede derribar toda la red.
  • Estrella: Todo se conecta a un central (switch/router). Fallo de un enlace no afecta al resto, pero depende del central.
  • Anillo: Los datos viajan de dispositivo en dispositivo. Útil para redes de alta velocidad con token passing.
  • Malla: Múltiples rutas entre nodos. La red más resistente: si un camino falla, los datos encuentran otro.

Protocolos que todo técnico debe conocer

Los acuerdos que hacen posible la comunicación.

HTTP/HTTPS

El protocolo de la web. HTTPS añade cifrado mediante TLS para proteger la información en tránsito.

DNS

El directorio de internet. Traduce nombres de dominio a direcciones IP para que los humanos no memoricen números.

SSH

Shell seguro. Proporciona acceso remoto cifrado a equipos de red y servidores.

SNMP

Simple Network Management Protocol. Para monitorear y gestionar dispositivos de red.
